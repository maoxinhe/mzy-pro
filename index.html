Features

为玩家打造的实用功能

我们把启动、整合包、更新与服务器整合在一起，减少折腾，把时间留给游戏。

整合包一键下载

梦之韵官方整合包（327.8 MB）内置下载页一键安装，HTTP/3 快速通道，开箱即玩。

云端自动更新

启动时自动向云端报告版本，检测到新版即弹窗提示，一键更新，无需重装游戏。

官方群组

启动器内置梦之韵 QQ 群与官网入口，反馈问题、组队开黑一步直达。

多实例管理

自由创建与管理多个游戏实例，版本隔离互不干扰，切换即开即玩。

快速启动

多线程下载与启动优化，自动选择 Java 运行时，让游戏加载更快更稳。

樱花粉主题

薄荷粉主题与樱花山景壁纸，账号、皮肤、设置尽在掌控。
